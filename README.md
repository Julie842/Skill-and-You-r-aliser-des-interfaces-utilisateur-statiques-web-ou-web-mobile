# Skill-and-You-r-aliser-des-interfaces-utilisateur-statiques-web-ou-web-mobile

Ce projet est un exercice d'intégration web visant à créer et styliser un sommaire structuré à plusieurs niveaux d'imbrication en utilisant du HTML5 et du CSS3 pur.

📌 Aperçu du projet :

Le projet présente une carte centrée stylisée avec une bordure double et un titre impactant en majuscules avec un effet d'ombrage textuel tridimensionnel. Le sommaire combine différentes types de listes (ordonnées et non-ordonnées) pour structurer des informations géographiques, toponymiques et historiques.

Fonctionnalités CSS mises en œuvre :
Mise en page : centrage de bloc (margin: auto) et bordure personnalisée (border: 10px double).
Typographie et effets : majuscules (text-transform), espacement des lettres (letter-spacing) et ombres portées multiples sur le titre (text-shadow).
Puces et numérotation :
Chiffres romains majuscules (upper-roman) pour le niveau principal (I, II, III).
Lettres minuscules (lower-alpha) pour les sous-sections ordonnées (a, b, c).
Puces circulaires (disc) pour les listes non-ordonnées.
Positionnement des puces à l'intérieur du bloc (list-style-position: inside).
